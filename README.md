# TestAplikasi

Aplikasi CRUD sederhana berbasis ASP.NET MVC 5 (.NET Framework) dengan SQL Server.

## Fitur
- Login Multi Role (Admin & Pimpinan)
- Dashboard
- CRUD User (Admin)
- Laporan
- Session Authentication
- SQL Server Database

## Teknologi
- ASP.NET MVC 5 (.NET Framework)
- C#
- SQL Server
- Bootstrap Template
- ADO.NET

## Cara Menjalankan
1. Clone repository
2. Restore NuGet Packages
3. Ubah connection string di `Web.config`
4. Jalankan database SQL Server
5. Run project dengan IIS Express
